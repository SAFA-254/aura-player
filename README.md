# Aura Player — свой плеер для Spotify

Фон и цвета кнопок подстраиваются под обложку трека. Музыку играет приложение Spotify
(на телефоне, ПК или колонке), а Aura показывает, что играет, и управляет им.

**Что умеет:**
- Управление: пауза, перемотка, треки, перемешивание, повтор, лайк, выбор устройства и громкость.
- Медиатека (плейлисты, любимые треки), поиск, очередь.
- **Текст песни**, синхронный с музыкой (из открытой базы LRCLIB). Нажатие на строку перематывает к ней.
- **Статистика**: топ треков и артистов за 4 недели, 6 месяцев и всё время, история прослушиваний.
- **Карточка «Сейчас слушаю»** для сторис (меню трека → «Поделиться карточкой»).
- **Темы**: Аура, Винил (крутящаяся пластинка), Неон, Минимализм.
- **Визуализатор**: декоративный или настоящий, через микрофон.
- **Большой экран**: на ПК и планшете в горизонтальной ориентации — обложка, часы и текст песни. Можно не гасить экран.
- **Артисты и альбомы**: нажми на имя артиста или на название плейлиста или альбома вверху.
- **Добавить в плейлист** (кнопка «+»), в том числе в новый.

**Жесты:**
- свайп по обложке влево или вправо — сменить трек;
- двойной тап — лайк;
- долгое нажатие — меню трека;
- свайп вверх по экрану — очередь, вниз — медиатека;
- нажатие на название трека — меню трека.

Кнопка «Назад» на Android закрывает шторки, а не приложение.

Требования: **Spotify Premium** и установленное приложение Spotify.

## Шаг 1. Выложить сайт в интернет (бесплатно, GitHub Pages)

Телефону нужен адрес с `https://`, поэтому приложение надо где-то разместить.

1. Зарегистрируйся на github.com.
2. Нажми **New repository**, назови `aura-player`, выбери **Public**, нажми **Create repository**.
3. Нажми **uploading an existing file** и перетащи **все файлы из этой папки**
   (`index.html`, `style.css`, `app.js`, `sw.js`, `manifest.webmanifest` и папку `icons`).
   Нажми **Commit changes**.
4. Открой **Settings → Pages**. В разделе *Branch* выбери `main` и `/ (root)`, нажми **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://ТВОЙ_НИК.github.io/aura-player/`

## Шаг 2. Создать приложение в Spotify

1. Зайди на https://developer.spotify.com/dashboard под своим аккаунтом Spotify.
2. **Create app**:
   - App name: `Aura` (любое)
   - App description: любое
   - Redirect URI: `https://ТВОЙ_НИК.github.io/aura-player/` — **точно так же, со слешем в конце**
   - Отметь галочку **Web API**
3. Сохрани и скопируй **Client ID** (32 символа).
4. Если хочешь дать приложение другу: **Settings → User Management** и добавь его
   имя и e-mail от Spotify. В режиме разработчика можно добавить до 5 человек.

## Шаг 3. Установить на Samsung

1. Открой `https://ТВОЙ_НИК.github.io/aura-player/` в **Chrome** на телефоне.
2. Вставь Client ID и нажми **Войти через Spotify**.
3. Установи приложение: **⋮ → Добавить на главный экран → Установить**
   (или кнопка «Установить приложение» в самой Aura).
4. Aura появится среди приложений со своей иконкой и будет открываться
   на весь экран без браузера. Chrome при этом сам собирает для неё настоящий APK (WebAPK).

> В Samsung Internet тоже работает: **≡ → Добавить страницу на → Главный экран**.

## Как пользоваться

- Включи что-нибудь в Spotify или выбери плейлист в Aura (кнопка медиатеки слева сверху).
- Если пишет «Ничего не играет», открой Spotify на телефоне: он появится в списке устройств.
- Свайп по обложке влево/вправо переключает трек, двойной тап ставит лайк.

## Проверка на компьютере

```bash
python -m http.server 5173 --bind 127.0.0.1
```

Открой http://127.0.0.1:5173/. Чтобы на компьютере работал вход, добавь в Spotify Dashboard
ещё один Redirect URI: `http://127.0.0.1:5173/`. Кнопка «Посмотреть демо» работает и без Spotify.

## Отдельный APK-файл (по желанию, позже)

Если нужен именно `.apk`, например чтобы отправить другу:
1. Зайди на https://www.pwabuilder.com и вставь адрес своего сайта.
2. **Package for stores → Android → Generate**.
3. В архиве будет `.apk`, его можно поставить на телефон
   (разреши установку из неизвестных источников).

## Ограничения Spotify (не баги Aura)

- Без Premium управлять воспроизведением нельзя.
- Экран блокировки и шторка уведомлений остаются от Spotify.
- С 2026 года Spotify показывает список треков только **твоих** плейлистов.
  Чужие плейлисты всё равно можно слушать целиком кнопкой «Слушать».
- Поиск выдаёт до 10 результатов на каждый тип.

## Как поменять дизайн

- Цвета, размеры и анимации находятся в `style.css`. Основные переменные заданы в самом начале.
- Логика подбора цветов из обложки — функция `buildTheme` в `app.js`.
- Чтобы не вводить Client ID на каждом устройстве, впиши его в `CONFIG.clientId`
  в начале `app.js`.
